Oracle

Oracle und Peal sind Sequenzer von Musica Obscura. Beide wählst du mit [[Shift]] + [[seq]].

Oracle macht aus vier geomantischen Figuren, den Mothers, ein 16-Step-Pattern mit vier Spuren. Jede Spur spielt im Synth-Modus ein Intervall über der Taste, im Drum-Modus ihr eigenes Pad. Halte eine Taste, um zu spielen; lässt du sie los, stoppt das Pattern beim nächsten Step. Halte [[Shift]], während du die letzte Taste loslässt, dann rastet das Pattern ein und läuft weiter. Halte [[Shift]] und drehe orange nach links, um es zu stoppen.

[[Shift]] + weiß drücken schaltet das Bearbeiten der Spuren ein oder aus. Solange EDIT angezeigt wird, startet eine Taste nicht das Pattern, sondern setzt das Intervall der gewählten Spur über dem aktuellen Grundton bzw. ihr Drum-Pad. [[Shift]] + orange drücken schaltet im Synth-Modus durch zehn Akkord-Voicings.

[[lift]] kopiert das Pattern, [[drop]] fügt es ein. [[scissors]] schaltet die gewählte Spur stumm; [[Shift]] + [[scissors]] setzt das ganze Pattern zurück. [[Shift]] + die ersten vier weißen Tasten wählt Pattern 1 bis 4. [[Shift]] + G, A, H und C in der oberen Hälfte schaltet Fire, Air, Water und Earth stumm; [[Shift]] + das hohe Dis schaltet alle stumm. [[Shift]] + das hohe Cis startet oder stoppt das Pattern; halte zusätzlich [[REC]], um es von Anfang an aufs Tape aufzunehmen. Die Einstellungen werden gespeichert; nach dem Einschalten steht die Wiedergabe.
