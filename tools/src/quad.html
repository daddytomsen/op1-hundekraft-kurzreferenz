Quad LFO

Four LFOs in one, each with its own target. They can modulate the engine encoders, the envelope, the effect, and each other. Works on synths and drums.

  1. Press [[synth]] (or [[drum]]), hold [[Shift]] and press [[T4]].
  2. Turn blue to QUAD and press [[T4]].
  3. Push an encoder to select its LFO: blue is LFO 1, green 2, white 3, orange 4. The selected row is underlined.

Hold [[Shift]] and push an encoder to mute that LFO. It fades out, its row goes grey and MUTE takes the amount's place, and its target goes back to where you set it. Push again to unmute. The LFO keeps running while it's muted, so it comes back in time. The mute is saved with the sound.

On the LFO page, [[T4]] switches the LFO off and on. When off, modulation stops, the display ticks return to the centre and the page dims with LFO OFF. Press [[T4]] again to enable it.

The layout is the same as on the master LFO. The main page shows each LFO's wave on the right.

With + or - the LFO only goes one way from where you set the knob, but twice as far, just like on the master LFO. A negative amount flips the side.

The phase offset is no longer on a knob. A sound saved with an offset still plays it, and another LFO can still move it (the O target). Picking + or - for an LFO sets its offset to zero.

The targets are the four engine encoders, the envelope (attack, decay, sustain, release), the four effect encoders, and the frequency, amount or offset of any other LFO. Two LFOs on one target add up.

The types decide when the LFO restarts:

TypeBehaviour
VOICOne LFO per voice, free running
FREEOne LFO for all voices, free running
GATEOne per voice, restarts at every note
MONOOne for all, restarts at every note
SHOTOne cycle per note, then holds
RANDA new random value at every note

Lorenz x and Lorenz z follow the Lorenz attractor, the butterfly-shaped curve from chaos theory. The value swings from one wing to the other and never quite repeats; one cycle of Speed is about one swing. The chaos setting (R28 restless, down to R14 calm) isn't on a knob any more: new Lorenz LFOs run at R28, and a sound saved with another setting keeps it.
