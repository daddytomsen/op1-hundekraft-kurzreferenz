Starting in time with the tape

To record a sequencer in time, it and the tape have to start together. How you do that depends on how the sequencer starts.

Most sequencers start when you play a key: the stock ones, C64arp, Composer, Trail, HOLD, Oracle and Peal. Hold [[REC]] to arm the tape, then press the key. The sequencer and the recording start at the same moment. A key starts it at once, not on the next beat.

Euclid, Dots and Grids don't start from a key: a key only picks a note. Turning orange starts Euclid and Dots, and pushing it starts Grids, but none of these starts the tape. Instead, hold [[REC]] and press [[Shift]] + the high C#. That starts every slot and the tape together, from the first step. The same keys also work on Oracle and Peal.

Grids also starts and stops with a push of orange. That doesn't start the tape, so for a take, use the keys above. The idea is u/Infamous_Call_6492's.
