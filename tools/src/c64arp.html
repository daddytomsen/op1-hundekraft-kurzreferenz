C64 arpeggiator

An editable pitch table with per-step dwell time.

Choose C64arp in the sequencer browser: hold [[Shift]] and press [[seq]], turn blue to c64arp, then press [[seq]] to load it. With [[seq]] on, hold a note to set the root of its repeating table of relative pitches. Turn orange right to hold the notes after you let go, like the stock arpeggio, and left to release them. A step can last several base steps, so a short table can produce uneven rhythms.

Push any encoder again to return to the main page. [[Shift]] + blue sets table length, 1–16; [[Shift]] + orange sets Gate, 10–100%. Editing a preset marks the table as custom.

With the table OFF, the arpeggiator plays only the keys you hold, lowest to highest, with no added notes. Hold a chord to arpeggiate it. Rate, Octaves and Gate still apply. Turn blue right to get your table back unchanged. Editing a row also switches the table back on.

The tables after minor up/down add a few more colours. OCTAVE bounces between the root and the octave, the classic chip bass. DOM7 and DIM7 bring tension, AUG and SUS2 sound open and dreamy, ADD9 and MIN9 reach above the octave, and ALBERTI plays root, fifth, third, fifth, like a piano's left hand.

Turn blue right past the last table, ALBERTI, for RANDOM. The arpeggiator then plays the keys you hold, or the ones HOLD keeps, in random order and in a random octave within Octaves. It never plays the same note in the same octave twice in a row, so even a single key jumps around its octaves. With Octaves at 1, a single key just repeats. Rate and Gate work as before. Turn blue left to go back to the table you had.

Without hold, letting go of the last key stops playback. With hold on, the notes keep playing after you let go. Once every key is up, the next key you press starts a new set. Stop or reset clears held notes.

Settings and the edited table are saved separately for synth and drum mode. Held notes and the run state are not saved.
